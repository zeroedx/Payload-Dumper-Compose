## Payload Dumper Compose

在手机上直接解析和提取 OTA 包分区镜像的简单工具

## 功能特性

支持从完整 OTA URL 直接下载并解析 payload.bin

支持从本地文件读取 OTA zip 或 payload.bin

自动解析分区列表，展示分区名称、大小等信息

选择需要的分区，导出为 .img 文件
